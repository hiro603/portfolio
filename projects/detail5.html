ハンドメイドアクセサリーECサイト制作

ハンドメイドアクセサリーブランドのECサイトを制作しました。

Design Coding Responsive
サイトを見る

プロジェクト概要 Project Overview

本プロジェクトはポートフォリオ用に制作した仮想案件です。
ハンドメイドアクセサリーブランド「LIGNE」を想定し、商品一覧から商品詳細・カートまでの購入体験を一貫して設計したECサイトを制作しました。
ブランドの世界観を伝えるトップページに加え、ショップ・商品詳細・カート・会員登録・ご利用ガイド・FAQなど、ECに必要なページを一通り実装しています。
繊細で温かみのある商品の魅力が伝わるデザインと、迷わず購入まで進める導線設計を両立することを目的としています。

SNSや委託販売が中心で、自社で商品を販売できるECサイトを持っていない。

目的 Objective

ブランドの世界観を保ちながら、商品との出会いから購入完了までをストレスなく進められる自社ECサイトを構築する。 商品一覧の探しやすさと商品詳細の情報量を両立し、初めて訪れたユーザーでも安心して購入できる体験を目指しました。

Before

  • 販売チャネルがSNSと委託販売に限られ、機会損失が発生している
  • 商品を一覧で比較したり、カテゴリから探したりする手段がない
  • 送料や返品などの購入情報がまとまっておらず、購入のハードルが高い

After

  • 商品一覧からカートまで完結する自社販売チャネルを確立
  • カテゴリ分類と一覧ページで、目的の商品にすぐ辿り着ける構成を実現
  • ご利用ガイド・FAQを整備し、安心して購入できる環境を構築

ターゲット Target

日常に寄り添う、自分だけのアクセサリーを探している20〜40代の女性。

課題 Problem

  • SNSの投稿だけでは商品数が増えるほど過去の商品が埋もれ、比較・検討がしにくい。
  • 素材・サイズ・お手入れ方法などの詳細情報を伝える場がなく、購入をためらう要因になっている。
  • 注文のやり取りがDM中心で手間がかかり、購入完了までの離脱が多い。

解決策 Solution

  • カテゴリ別の商品一覧ページを用意し、目的の商品へ直感的に辿り着ける構成に整理。
  • 商品詳細ページに素材・サイズなどの情報を集約し、購入判断に必要な材料を提示。
  • カート・ご利用ガイド・FAQまでの導線を整備し、迷わず購入完了まで進める流れを設計。

ポイント Point

  • ブランドの世界観を伝える余白を活かしたビジュアル設計
  • カテゴリから商品を探しやすい一覧ページのUI設計
  • カートから購入完了までを意識した導線設計

デザイン Design

手仕事の繊細さと温かみが伝わるよう、余白を活かした上品なトーンでデザインしました。商品写真を主役に、装飾を抑えた構成にしています。 ECサイトとして情報の優先度を整理し、価格や購入ボタンなど行動につながる要素が自然と目に入るレイアウトを意識しています。

実装 Development

  • 商品一覧・商品詳細・カートなど、ECに必要な複数ページを共通パーツで効率的に構築。
  • SCSSを用いて保守性・再利用性の高いスタイル設計を実施。
  • JavaScriptでカートへの追加・数量変更などのインタラクションを実装。
  • モバイルファーストでコーディングし、スマートフォンでも快適に購入できるUIを実現。

制作プロセス Production Process

ブランドの世界観と購入のしやすさを両立し、各デバイスで快適に買い物ができるECサイトとして制作しました。

  • GPTを活用したデザインイメージの作成：GPTを活用してブランドコンセプトやビジュアルイメージを検討し、ハンドメイドアクセサリーECにふさわしい世界観やページ構成の方向性を整理しました。
  • Claude DesignとClaude Codeによる初期実装：Claude DesignとClaude Codeを活用してHTML・CSS・JavaScriptの初期実装を行い、複数ページにわたるECサイトを効率的に構築しました。
  • 手作業による品質向上：生成されたコードをベースに、クラス設計の見直しやSCSSの整理、レスポンシブ調整、カート周りのUI実装を手作業で行いました。保守性・可読性・再利用性を意識しながら品質を高めています。
