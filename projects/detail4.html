ハンドメイドアクセサリーLP制作

ハンドメイドアクセサリーのランディングページを制作しました。

Design Coding Responsive
サイトを見る

プロジェクト概要 Project Overview

本プロジェクトはポートフォリオ用に制作した仮想案件です。
作家の想いや商品の魅力を伝えながら、ユーザーがスムーズに商品を探し購入できる体験を目指しています。
温かみのあるデザインと視認性の高いレイアウトを両立し、ブランドイメージの向上と購買促進を目的としています。
また、SNS経由の流入が多いため、初めて訪れるユーザーにもブランドの魅力が伝わる設計が求められます。
レスポンシブ対応を行い、スマートフォンでも快適に閲覧できるよう実装しています。

クライアント Client

業種

ハンドメイドアクセサリーの企画・製作・販売を行うD2Cブランド

対象

20〜40代の女性、量産品ではなく特別感のあるアクセサリーを求めている。

強み

一点一点手作業で制作されたオリジナルアクセサリーで、素材やディテールにこだわった高品質な商品。

現状

SNS経由で一定の集客はできているが、商品やブランドの魅力を十分に伝えられる販売チャネルが不足している。

  • 制作期間

    2026年6月6日〜2026年6月7日(2日)

  • 使用技術

    HTML / CSS / javascript

  • 担当範囲

    デザイン / コーディング

  • サイトURL

    サイトを見る

目的 Objective

ブランドの世界観と商品の魅力を効果的に伝え、ユーザーが安心して商品を購入できるECサイトを構築する。あわせて、商品検索性や回遊性を向上させ、購入率の向上を目指す。 また、スマートフォンからの閲覧にも配慮し、幅広いユーザーにとって使いやすいUI設計を行いました。

Before

  • ブランドの魅力やコンセプトを十分に伝えられていない
  • 商品数の増加により、目的の商品を見つけにくい
  • 商品情報が整理されておらず、回遊性が低い

After

  • ブランドコンセプトや作家の想いが伝わり、世界観への共感を促進
  • 導線を整理し、商品を探しやすい構成を実現
  • サイト内回遊率と購入機会の向上を実現

ターゲット Target

自分らしさを表現できるアクセサリーを探している、20〜40代の女性。

課題 Problem

  • SNSでは、ブランドコンセプトや作家の想いがユーザーに伝わりにくい。
  • 商品数の増加に伴い、目的の商品へたどり着きにくく、離脱につながっている。
  • 素材やサイズ感、商品の特徴が十分に伝わらず、購入をためらう要因となっている。

解決策 Solution

  • コンセプトや制作へのこだわりを視覚的に伝えることでブランドへの共感を促進。
  • レイアウトを整理し、ユーザーが直感的に商品を探せる構成を採用。
  • ユーザーが複数の商品を比較・検討しやすい導線を設計。

ポイント Point

  • ブランドの世界観を伝えるビジュアル設計
  • 写真を引き立てるレイアウト設計
  • 商品を探しやすいUI設計
  • 購入を後押しする商品ページ

デザイン Design

ハンドメイドアクセサリーの温かみと上質感を表現しました。アクセントカラーで、商品写真が引き立つデザインを意識しています。 また、情報を整理して配置することで、ユーザーが迷わず閲覧できる読みやすいUIを実現しています。

実装 Development

  • HTMLのセマンティックなマークアップを意識して構築。
  • SCSSを用いて保守性・再利用性の高いスタイル設計を実施。
  • JavaScriptによるハンバーガーメニューやUIアニメーションを実装

制作プロセス Production Process

サロンの世界観と情報の見やすさを両立し、各デバイスで快適に閲覧できるWebサイトとして制作しました。

  • GPTを活用したデザインイメージの作成：GPTを活用してサイトのコンセプトやビジュアルイメージを検討し、ハンドメイドアクセサリーブランドにふさわしい世界観やレイアウトの方向性を整理しました。
  • Claude DesignとClaude Codeによる初期実装：Claude DesignとClaude Codeを活用してHTML・CSS・JavaScriptの初期実装を行い、効率的にフロントエンドを構築しました。
  • 手作業による品質向上：生成されたコードをベースに、クラス設計の見直しやSCSSの整理、レスポンシブ調整、細かなUIの実装を手作業で行いました。保守性・可読性・再利用性を意識しながら品質を高めています。
