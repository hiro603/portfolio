コーポレートサイト制作

金属加工会社のコーポレートサイト制作しました。

Design Coding Responsive

  • 制作期間

    2025年1月1日〜2025年1月31日(30日)

  • 使用技術

    HTML / CSS / javascript

  • 担当範囲

    デザイン / コーディング

  • サイトURL

    サイトを見る

01 目的・課題

既存のサイトは情報が整理されておらず、必要な情報に辿り着きにくい状態でした。 信頼感の向上と問い合わせ増加を目的に、リニューアルを行いました。

Before

  • 情報が散在していた
  • スマホ表示が見づらい
  • 会社の強みが伝わりにくい

After

  • 情報設計を見直し、整理
  • レスポンシブ対応でスマホでも見やすく
  • 強みや実積を分かりやすく訴求

02 ターゲット

製造業の発注担当者・企業の購買担当者

03 工夫したポイント

  • 余白を活かしたシンプルで見やすいデザイン
  • 視線誘導を意識したレイアウト
  • スマホでも快適に閲覧できるレスポンシブ対応
  • スクロールアニメーションで上質な印象を演出
